# M1.4.3 — exact no-op filesystem factory correction

M1.4.3 is a compile-only correction over immutable M1.4.2.

The M1.4.2 target compiler reported that `microStore::NoopFileSystem` does not name a type and that `microStore::FileSystem` has a constructor taking `microStore::FileSystemImpl*`. M1.4.3 stops aliasing the no-op adapter as a type and instead evaluates `microStore::NoopFileSystem()` directly as the adapter factory expression.

A compile-time `decltype(microStore::NoopFileSystem())` and `std::is_constructible` assertion now validates the factory result against `microStore::FileSystem` using the actual resolved dependency during the PlatformIO compile.

The release preflight was also corrected: static source checks may protect local invariants, but they no longer claim to verify an external API. The script reports `STATIC PASS` and leaves external API verification open until PlatformIO successfully compiles the target.

No networking, storage, radio-profile or UI behavior is intentionally changed beyond version strings.
