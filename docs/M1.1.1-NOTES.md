# M1.1.1 notes — dependency pin hotfix

M1.1.1 contains no intended protocol or radio behavior change from M1.1.

## Fix

M1.1 incorrectly used the abbreviated Git commit `290a133` in PlatformIO `lib_deps`. PlatformIO invokes Git fetch with the fragment as a ref, and GitHub does not expose abbreviated object IDs as fetchable remote refs. This caused dependency installation to fail before compilation began.

M1.1.1 pins the exact RatSpeak microReticulum commit with the full 40-character object ID:

```text
290a1336ebe05782c80a1debf8a8da0316a88ae7
```

This is the commit paired with rsCardputer v1.7.9's Python Reticulum/LXMF interoperability fix.

## Release rule

For PlatformIO Git dependencies, use a release tag/branch or a full immutable 40-character commit ID. Do not use abbreviated SHAs.

M1.1 remains an immutable failed-build artifact; this corrected package is versioned M1.1.1 rather than silently replacing it.
