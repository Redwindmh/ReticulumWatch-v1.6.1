# ReticulumWatch v1.6.0-rc1 Release Notes

## Scope
Final UX/stabilization milestone. No Reticulum, LXMF wire-format, radio, storage-format, Codec2, or power-path changes.

## UI fit
- Generic headers now use 164 px between Back/Home and reduce long titles to Montserrat 10 instead of clipping at a fixed 150 px.
- Conversation headers now use Back + a 156 px peer title + compact `i` button. Peer management remains on Peer Details.
- Thread canned replies are labelled `1` and `2`. Notification canned replies use the same numbering.
- Bottom chat controls are explicitly laid out inside x=1..229: `1`, `2`, `PTT`, `VOICE`, `REPLY`.

## Haptics
- General UI taps now use DRV2605 Strong Click (effect 1).
- Keyboard input uses a dedicated Strong Click path with its own debounce, so typing feedback is not suppressed by a preceding UI tap.
- Existing RX/TX multi-pulse message haptics remain unchanged.

## Navigation
The chat `i` action opens Peer Details and sets Back to return to the chat.
