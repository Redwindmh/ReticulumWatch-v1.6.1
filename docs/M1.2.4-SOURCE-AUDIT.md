# M1.2.4 source audit

## Scope

Source audit for the on-screen software restart patch.

## Architectural checks

- `WatchUI` only presents restart controls and asks `WatchHardware` to restart.
- `ESP.restart()` is contained in `WatchHardware::restart()` rather than scattered into UI code.
- Restart is confirmation-gated; an accidental tap on the inbox RST control does not immediately reboot.
- The restart path deliberately does not trigger haptics, avoiding unnecessary load on a path whose only purpose is a reliable reboot.
- Restart does not erase, format, rename, or migrate the Reticulum partition.
- No changes were made to radio/Reticulum/LXMF/storage behavior other than active version strings/comments.

## UI geometry check

Inbox header is 230 px wide.

- title: left aligned, Montserrat 14;
- RST: 42x27, right-aligned with -56 px offset;
- ANN: 50x27, right-aligned with -2 px offset.

This leaves an intentional gap between the title and controls and a 4 px gap between RST and ANN.

Restart confirmation uses only the fixed 240x240 root and contains no scroll-dependent control.

## API/signature checks

New LVGL calls reuse APIs already present in the proven source (`lv_label_create`, `lv_obj_set_width`, `lv_obj_align`, `makeButton`).

`WatchHardware::restart()` is declared `[[noreturn]]`; after `ESP.restart()` an unreachable defensive loop preserves that contract if control unexpectedly returns.

## Verification limit

PlatformIO is not installed in the generation environment. This is a static/source audit, not a successful target build.
