# ReticulumWatch v1.3.0 hardware test

## New feature: Peer Details

1. Boot normally and open **Menu -> Peers**.
2. Confirm each peer row shows its name/hash plus `h=<n>` and `seen <age>`.
3. Tap a peer. It should open **PEER DETAILS**, not jump directly to the conversation.
4. Confirm the screen shows:
   - full 32-hex destination hash;
   - hop count;
   - last-seen age and UTC timestamp;
   - LXMF verified/sendable status;
   - `Active Link: YES` when that peer currently has the live reply Link, otherwise `no`;
   - CONTACT / ANNOUNCE / HISTORY-MANUAL source information.
5. Test the four bottom actions:
   - **CHAT** opens the existing conversation;
   - **NAME** opens contact-name editing;
   - **STAR** toggles favorite and returns to refreshed peer details;
   - **QR** shows the peer's LXMF hash and Back returns to Peer Details.
6. Repeat from **Contacts** and confirm tapping a contact also opens Peer Details.

Expected serial line when details opens:

```text
[v1.3:peer] details name=... hops=... last_seen=... active_link=... sendable=... verified=...
```

## Regression checks
