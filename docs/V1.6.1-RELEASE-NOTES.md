# ReticulumWatch v1.6.1 — Final Maintenance Release

## Purpose

Remove the non-LXST PTT-burst experiment from the final user interface while retaining the useful interoperable LXMF recorded-voice workflow.

## Changes

- Removed the conversation `PTT` button.
- Removed PTT press/release callbacks, PTT recording state, and PTT-specific diagnostics/status copy.
- Kept the `VOICE` workflow: RECORD -> optional PLAY -> SEND.
- Kept Codec2 700C outbound LXMF audio and legacy Codec2 450 playback compatibility.
- Kept stored incoming voice playback and playback progress.
- Reflowed the bottom chat action row to `1`, `2`, `VOICE`, `REPLY` with wider VOICE/REPLY controls.

## Protocol scope

No Reticulum packet framing, radio behavior, LXMF field format, Codec2 mode, storage format, power/wake behavior, or VoiceService send/playback semantics changed. The removed PTT path was a local UI interaction layered over recorded LXMF audio, not true LXST PTT.

## Final status

This release is intended to close the current ReticulumWatch development cycle. Future real-time PTT/telephony work should be a separate LXST-based project/version rather than reusing the removed experimental button.
