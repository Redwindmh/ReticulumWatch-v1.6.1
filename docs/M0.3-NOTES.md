# M0.3 — Reticulum core + persistent identity

M0.3 is the first build that links and starts microReticulum.

## Acceptance criteria

1. microReticulum 0.5.0 starts without exception.
2. On the first M0.3 boot, `/rns/identity.key` is created as a 64-byte raw Reticulum identity.
3. The firmware prints an identity hash and a Reticulum destination hash.
4. After resetting without reflashing, the firmware reports that it reloaded the identity.
5. The identity hash and destination hash are identical before and after reset.
6. The SX1262 remains in standby. This milestone performs no RF transmission.

## Why RF is not attached yet

The next integration boundary is the Reticulum `InterfaceImpl` adapter plus RNode-compatible LoRa packet framing and a network-specific radio profile. Keeping that separate lets us prove cryptographic identity persistence, memory use, and the RNS event loop before diagnosing RF profile/framing issues.
