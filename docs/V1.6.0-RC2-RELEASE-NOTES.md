# ReticulumWatch v1.6.0-rc2 release notes

RC2 is a photo-informed UI stabilization pass over RC1. No Reticulum, radio, LXMF, Codec2, storage, power, or wake protocol behaviour is intentionally changed.

## Changes
- Canned-reply editor header shortened from `CANNED REPLY 1/2` to `REPLY 1/2` so the title no longer collides with the SAVE button on the physical 240x240 display.
- Display-name editor header shortened to `NAME`.
- Editor helper copy shortened to `Blank = disabled` or `Saved immediately` to avoid crowding immediately above the keyboard.
- RC1 chat header simplification retained: wide peer title plus compact `i` button.
- RC1 numeric canned reply buttons `1` and `2` retained.
- RC1 stronger general haptic feedback and dedicated keyboard haptic feedback retained.

## Scope
This is a release-candidate visual/UX correction only. The frozen Reticulum/radio boundary remains protected by source-hash preflight checks.
