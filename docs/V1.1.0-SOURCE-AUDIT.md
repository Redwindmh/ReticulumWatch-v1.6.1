# ReticulumWatch v1.1.0 — Source Audit

## Parent baseline

Hardware-accepted `ReticulumWatch-v1.0.0`.

## Intended runtime source changes

Only these product-source files are intentionally changed:

1. `src/config/BuildConfig.h`
   - version `1.0.0` -> `1.1.0`.

2. `src/ui/WatchUI.cpp`
   - home clock scale `288` -> `304` on X and Y;
   - home clock alignment x-offset `0` -> `-4`;
   - comments updated to describe the optical-centering rationale.

3. `platformio.ini`
   - internal release marker `RW_MILESTONE=100` -> `110`.

The release preflight script is updated only so its expected version/build marker matches v1.1.0.

## Frozen boundary

Reticulum, radio and partition-map hashes remain checked against the long-standing hardware-accepted frozen hashes. No protocol-facing source change is intended in this release.

## Risk assessment

Low. The functional delta is confined to LVGL watch-face presentation plus release identity. Wake, storage, audio and communications paths are unchanged.
