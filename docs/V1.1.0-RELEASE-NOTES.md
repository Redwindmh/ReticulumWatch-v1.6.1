# ReticulumWatch v1.1.0 — Home Face Refinement

## What changed

v1.1.0 is the first post-stable refinement release. The original M0-M13 roadmap is complete; this release begins semantic-versioned maintenance and improvement after v1.0.0.

Runtime changes relative to hardware-accepted v1.0.0 are intentionally narrow:

- home-screen time scale increased from LVGL transform `288` (~112.5%) to `304` (~118.75%);
- home-screen time receives a 4 px left optical correction (`x = -4`) while retaining the same vertical position;
- date, battery indicator, message button and menu button positions are unchanged;
- firmware version changes from `1.0.0` to `1.1.0`;
- internal release marker changes from `RW_MILESTONE=100` to `RW_MILESTONE=110`.

## What did NOT change

No change was made to:

- SX1262 radio profile/framing;
- Reticulum or LXMF endpoint behavior;
- persistent identity or storage format;
- Codec2/audio behavior;
- connected standby;
- crown wake;
- BMA423 lift-to-wake;
- touch-wake policy;
- contacts, peers, message history or recovery console.

The frozen Reticulum/radio boundary remains byte-for-byte protected by release preflight.

## Why the clock is shifted left

The v1.0.0 clock object was geometrically centered at x=0, but the rendered five-character `HH:MM` glyph group appears slightly right-heavy on the physical 240 px display. v1.1.0 therefore uses a small explicit optical correction rather than disturbing the entire face layout.
