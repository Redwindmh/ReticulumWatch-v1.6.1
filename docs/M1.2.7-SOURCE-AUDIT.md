# M1.2.7 source audit

## Baseline

M1.2.6 remains immutable. M1.2.7 is issued only to fix its C++ compile error.

## Compiler evidence

The M1.2.6 user build failed only in `src/ui/WatchUI.cpp` with repeated:

```text
invalid conversion from 'int' to 'lv_buttonmatrix_ctrl_t'
```

The errors originated from the custom control-map macros and the raw width value `3`.

## Change boundary

Changed behavior/code:

- `src/ui/WatchUI.cpp`: explicitly typed control-map helpers; active version diagnostic.
- version-only strings in `BuildConfig.h`, `main.cpp`, and `LxmfService.cpp`.
- README/milestone/audit documentation.

Frozen against M1.2.6:

- StorageService
- RadioService
- WatchLoRaInterface
- ReticulumService
- RNS compatibility layer
- RadioConfig
- platformio.ini

## Verification performed before packaging

- scanned the complete supplied build log for every `error:` line; all were the same
  enum-conversion family in the keyboard control maps;
- compiled a strict C++17 enum/control-map reproducer using the M1.2.7 helper pattern;
- verified the text/special control-map element counts still match their button maps;
- ZIP integrity test;
- byte comparison of frozen networking/storage files against M1.2.6.

PlatformIO is not installed in the artifact environment, so this source is not marked
PlatformIO build-verified until the user build succeeds.
