# ReticulumWatch v1.5.0 source audit

Parent: hardware-accepted v1.4.0.

## Functional changes

- `src/ui/WatchUI.cpp/.h` — voice/PTT state presentation, active-Link gating in UI, live record/playback progress.
- `src/audio/AudioService.cpp/.h` — adds read-only `playbackMs()` for UI progress.
- version/release documentation and preflight bookkeeping.

`src/audio/VoiceService.cpp/.h` is not changed. LXMF voice encoding/sending semantics therefore remain on the previously accepted Codec2 700C `FIELD_AUDIO` path.

## Frozen boundary

Release preflight continues SHA-256 enforcement for the accepted Reticulum/radio/config/partition files. v1.5 does not modify them.

## Verification boundary

Static preflight, partition validation, source diff and archive integrity can be checked here. PlatformIO target compilation and hardware/audio interoperability remain user-side acceptance gates.
