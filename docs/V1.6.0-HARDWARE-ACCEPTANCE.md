# ReticulumWatch v1.6.0 hardware acceptance

v1.6.0 is a metadata-only graduation of v1.6.0-rc2.

The RC2 hardware run confirmed:
- successful boot and hardware bring-up;
- persistent Reticulum identity and LXMF history restore;
- Reticulum endpoint/radio initialization;
- audio and Codec2 voice initialization;
- connected standby with Reticulum RX preserved;
- crown wake;
- stable navigation through Messages, Contacts and Settings;
- accepted final visual/haptic UX from user testing.

Because the runtime source is unchanged from RC2, v1.6.0 inherits that hardware acceptance.
