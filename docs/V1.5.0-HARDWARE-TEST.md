# ReticulumWatch v1.5.0 hardware test

## 1. Build / boot

Build and flash `twatch_s3_16mb`. PASS: boot completes as `1.5.0`, text messaging remains available, no reset loop.

## 2. Conversation with no active Link

Open a peer conversation for which the watch has no current reply Link.

PASS:
- status says `PTT needs active Link | VOICE can preview locally`;
- PTT is disabled;
- REPLY and normal text messaging still work.

## 3. Establish an active Link

Have the peer send a Link-based LXMF message to the watch, then return to that conversation.

PASS: status changes to `Hold PTT to record | release to send` and PTT becomes usable.

## 4. Hold-to-talk PTT

Hold PTT for about 1-2 seconds while speaking, then release.

PASS:
- button reads `REC` while held;
- status shows increasing record duration;
- release changes status through encoding/sending;
- an outgoing `[VOICE]` message is added exactly once;
- serial includes `[v1.5:ptt] pressed` and `[v1.5:ptt] released`;
- peer can receive/decode if interoperable with the established v1.4 voice path.

## 5. VOICE composer

Open `VOICE` from a conversation. RECORD a short clip, optionally PLAY it, then SEND.

PASS:
- recording time updates live;
- playback shows elapsed/total time;
- SEND queues Codec2 encoding and submission;
- failure (for example no active Link) is shown as a truthful error rather than delivery success.

## 6. Incoming voice playback

For a conversation containing a stored voice sidecar, use `PLAY LATEST VOICE`.

PASS: preparation is shown, playback starts, elapsed/total time advances, and the UI returns to idle after playback.

## 7. Regression

Confirm:
- text RX/TX and the `Sending message...` popup;
- Peer Details / Contacts / Peers navigation;
- black chat windows with white text;
- connected standby RX;
- crown wake and lift wake.
