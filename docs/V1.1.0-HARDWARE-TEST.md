# ReticulumWatch v1.1.0 — Hardware Test Guide

This release has one intended visible UI change. Test that change first, then perform a short regression smoke test.

## 1. Boot/version — required

### Do
Flash and boot normally.

### Look for on the watch
The watch face appears normally and the UI remains responsive.

### Look for in serial

```text
Reticulum Watch 1.1.0 booting...
[boot] 1.1.0 initialization complete
```

### PASS
No startup regression or DEGRADED Reticulum/LXMF state.

---

## 2. Home-screen clock size — NEW in v1.1.0

### Do
Return to the home/watch face and compare it with v1.0.0 by eye.

### Look for
- `HH:MM` digits are slightly larger than v1.0.0;
- the time still fits comfortably without clipping;
- the date remains clearly separated below it;
- battery and bottom navigation controls do not overlap the time.

### PASS
The time is visibly larger but still clean and unclipped.

---

## 3. Home-screen clock centering — NEW in v1.1.0

### Do
View several times if convenient, especially values with visually uneven digits such as `11:11`, `12:34`, or `20:58`.

### Look for
The time should appear centered on the physical watch face rather than slightly right of center.

Implementation change: the label uses a 4 px optical left correction.

### PASS
The time looks visually centered. If it still looks right- or left-heavy, report which direction and approximately how much; this can be tuned without touching the rest of the UI.

---

## 4. Wake regression — required smoke test

### Do
Let the display sleep, then test crown wake and Lift to Wake.

### Look for
- crown wakes normally;
- a natural wrist raise wakes normally;
- sleeping glass taps still do not wake the display.

### Serial evidence for lift

```text
[m12:motion] hardware lift event latched
[m12:power] wake source=lift
```

### PASS
Wake behavior is unchanged from accepted v1.0.0.

---

## 5. LXMF regression — required smoke test

### Do
Receive one ordinary LXMF text message and send one reply from the watch.

### PASS
Both directions work and message history remains usable.

---

## 6. Persistence regression — recommended

### Do
Reboot once.

### PASS
Identity, settings, message history, display timeout and Lift to Wake preference persist.

---

# Short result format

Please report:

```text
v1.1.0
1 Boot: PASS/FAIL
2 Time size: PASS/FAIL + comment
3 Time centering: PASS/FAIL + comment
4 Crown/Lift wake: PASS/FAIL
5 LXMF RX/TX: PASS/FAIL
6 Persistence: PASS/FAIL
```

The two most important observations for this release are **time size** and **time centering**.
