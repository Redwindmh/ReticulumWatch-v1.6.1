# M1.1.3 notes — explicit microReticulum dependencies

M1.1.3 is a build-system correction to M1.1.1. It does not intentionally change
Reticulum, LXMF, radio, storage, or UI runtime behavior.

## Failure observed in M1.1.1

The RatSpeak microReticulum Git dependency downloaded correctly and compilation
progressed into its cryptography sources, then stopped because the consuming
project had not declared microReticulum's external libraries:

- `Cipher.h: No such file or directory`
- `Ed25519.h: No such file or directory`
- `RNG.h: No such file or directory`

Those headers are supplied by the Arduino Crypto library. microReticulum also
depends on ArduinoJson and MsgPack.

## Correction

`platformio.ini` now pins all three explicitly:

```ini
bblanchon/ArduinoJson @ 7.4.2
hideakitai/MsgPack @ 0.4.2
rweather/Crypto @ 0.4.0
```

The RatSpeak microReticulum fork remains pinned to the full immutable commit:

```text
290a1336ebe05782c80a1debf8a8da0316a88ae7
```

## Verification status

The provided user build log proves M1.1.1 fetched the intended microReticulum
revision successfully and failed during compilation before any esptool flashing
step. M1.1.3 has been source-audited against that failure. A complete PlatformIO
build must still be run on the target development machine.
