# ReticulumWatch v1.0.0 — Source Audit

## Parent

M13 hardware-accepted release-candidate source.

## Runtime source changes

Only the stable build identity changes:

- `src/config/BuildConfig.h`: `kVersion` from `M13` to `1.0.0`.
- `platformio.ini`: internal release marker from `RW_MILESTONE=13` to `RW_MILESTONE=100`.

No Reticulum, LXMF, radio, storage, audio, power-manager, BMA423 wake, recovery-service or UI behavioral implementation file was intentionally changed for stable graduation.

## Documentation/tooling changes

- stable README;
- v1.0.0 release notes;
- v1.0.0 hardware test guide;
- roadmap/milestone/mistake-ledger stable-release entries;
- release preflight updated to assert stable version identity and required stable docs.

## Safety decision

Lift sensitivity is not modified. M13 hardware evidence proves the accepted interrupt-driven TILT wake path. Stable graduation must not replace that path with speculative motion polling or an undocumented SensorLib patch.
