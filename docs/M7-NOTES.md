# M7 — Identity and Exchange Tools

Hardware acceptance was reported on 2026-09-12.

Accepted behavior included:

- public identity screen;
- raw LXMF destination QR display;
- continued connected standby;
- incoming Link establishment;
- incoming LXMF persistence;
- quick-reply transmission.

Exchange format deliberately uses the standard raw 32-hex LXMF destination address rather than a ReticulumWatch-only URI. Public identity hashes are shown separately. Private identity material is not part of casual QR exchange.
