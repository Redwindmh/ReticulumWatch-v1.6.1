# M2.6.0 Source Audit

## Frozen from hardware-accepted M2.1.0

The release preflight SHA-256-locks `RadioService`, `WatchLoRaInterface`, `ReticulumService`, `RadioConfig`, and both partition CSVs.

## Mutable M2 layers

- `StorageService`: delivery overlays and peer/contact sidecars; LMX1/2/3 record layout retained.
- `LxmfService`: announce handler, peer cache integration, receipt/proof state, bounded retry/path recovery.
- `WatchUI`: conversations, threads, peers, contacts, manual destination, composer, quick replies.

## Dependency contracts

- microReticulum remains pinned at 0.5.0.
- microStore remains pinned at 0.1.7 with `USTORE_USE_NOOPFS=1`.
- RNS internal persistence/provisioning remain disabled; application identity/history stay on the dedicated FFat partition.
- PacketReceipt delivery state is only promoted to `DELIVERED` from an actual proof callback.

## Compatibility principle

M2 metadata is sidecar state. The CRC-protected LMX3 journal is not rewritten to store contacts, read state, delivery attempts, or retry notes.
