# M1.2.6 source audit

## Version discipline

M1.2.5 remains immutable. This patch is issued as M1.2.6.

## Functional source change

Only `src/ui/WatchUI.cpp` receives functional behavior changes:

- custom lower/upper/special LVGL keyboard maps;
- matching control maps;
- larger keyboard geometry;
- slightly smaller textarea geometry;
- key popovers;
- keyboard item font size 14.

`BuildConfig.h`, `main.cpp` and `LxmfService.cpp` change active version/diagnostic text only.

## LVGL API audit

M1.2.6 relies on the LVGL 9.4 public API:

```cpp
void lv_keyboard_set_map(
    lv_obj_t * kb,
    lv_keyboard_mode_t mode,
    const char * const map[],
    const lv_buttonmatrix_ctrl_t ctrl_map[]);
```

and the public `LV_KEYBOARD_CTRL_BUTTON_FLAGS` macro.

Control-map lengths:

- lower/upper: 34 buttons;
- special: 35 buttons.

Compile-time assertions in `WatchUI.cpp` guard these control-map sizes.

## PlatformIO status

PlatformIO is unavailable in the artifact-generation environment. This source audit is not equivalent to a real PlatformIO build.

## Local keyboard syntax audit

The exact custom map/control declarations and the LVGL 9.4 `lv_keyboard_set_map()` call shape used by this patch were passed through a local `g++ -std=gnu++17 -Wall -Wextra -Werror -fsyntax-only` audit stub. The audit completed successfully.

This only checks the new C++ declarations/call signatures; it is not a substitute for the real PlatformIO build.
