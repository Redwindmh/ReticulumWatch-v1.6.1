# ReticulumWatch v1.4.0 Source Audit

Parent: hardware-accepted `v1.3.0-build3`.

## Product source/config changes

- `src/config/BuildConfig.h`
  - version `1.3.0-build3` → `1.4.0`.
- `platformio.ini`
  - release marker `131` → `140`.
- `src/hal/WatchHardware.cpp`
  - removes 1 Hz diagnostic accelerometer I2C sampling in connected standby;
  - standby heartbeat becomes 60 s and no longer reads XYZ;
  - irrelevant motion IRQ logging is rate-limited to 15 s;
  - real tilt/wakeup events remain immediate.
- `src/power/PowerManager.h/.cpp`
  - adds current-session active/standby time accounting;
  - adds standby-entry, crown-wake and lift-wake counters.
- `src/ui/WatchUI.cpp`
  - Power screen displays session counters;
  - sleeping UI notification polling changes from 350 ms to 1200 ms;
  - active-screen UI cadence remains 350 ms.

## Frozen boundary

The preflight continues exact SHA-256 verification of the accepted Reticulum/radio files and partition maps. v1.4 does not modify them.

## What this does not prove

Static/source audit cannot prove actual battery-runtime improvement. Hardware battery/runtime measurements are required. It also cannot replace a PlatformIO target compile, which is unavailable in the assistant environment.
