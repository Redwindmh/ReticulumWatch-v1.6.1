# M0.3.8 Notes — no-op filesystem registration

M0.3.7 proved that the microStore compatibility generator works on the user's PlatformIO environment and detected the `Adapters::NoopFileSystem` factory form. Runtime then stopped because Reticulum Watch treated `FileSystem::init() == false` as fatal.

The upstream firmware only warns on a false filesystem init result and continues. M0.3.8 mirrors that lifecycle: call init for diagnostics, register the filesystem unconditionally, then let `Reticulum::start()` determine whether the RNS core can proceed.

No RF interface is attached and no RF transmission is performed.
