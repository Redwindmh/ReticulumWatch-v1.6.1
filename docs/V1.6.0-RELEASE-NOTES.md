# ReticulumWatch v1.6.0 release notes

ReticulumWatch v1.6.0 is the final stable graduation of the hardware-accepted v1.6.0-rc2 release candidate.

## Release status

- Functional source is unchanged from v1.6.0-rc2.
- Only stable-version metadata, release documentation, and preflight expectations changed.
- The v1.6.0-rc2 hardware test was accepted before graduation.

## Final feature set

- Standalone Reticulum/LXMF messaging over SX1262 LoRa.
- Persistent identity, peer/contact metadata, message history, delivery state, and recovery tooling.
- Opportunistic/path-request transmission plus active-Link reply path.
- Peer Details with hop/last-seen/link metadata and local pinning.
- Black/white conversation UI, improved 240x240 title/layout fit, numeric canned replies, and strong haptic/keyboard feedback.
- Codec2 700C LXMF voice messages with PTT/voice UX and playback progress.
- Crown and BMA423 lift-to-wake with connected standby that keeps Reticulum RX online.
- Power/session diagnostics and bounded storage/recovery safeguards.

## Stable-release policy

This release is feature-frozen. Future changes should be regression fixes or clearly versioned new development rather than edits to this artifact.
