# M0.3.4 Notes

M0.3.3 demonstrated that `Reticulum::start()` still requires a registered filesystem
object even when `RNS_USE_FS` and provisioning are disabled.

M0.3.4 follows current upstream standalone firmware behavior:

1. Create a microStore `NoopFileSystem`.
2. Initialize it.
3. Register it through `RNS::Utilities::OS::register_filesystem()`.
4. Start Reticulum.
5. Keep the watch's permanent identity in Reticulum Watch `StorageService`.

The no-op store is temporary. A rooted persistent microStore adapter will be introduced
before path-table / known-destination / transport-node persistence is enabled.
