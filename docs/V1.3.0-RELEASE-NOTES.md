# ReticulumWatch v1.3.0 release notes

## What changed

- Added a dedicated **Peer Details** screen.
- Tapping a peer/contact now opens details before the conversation.
- Peer details show the full 128-bit LXMF destination hash, display/announced name, hop count, last-seen age and UTC timestamp, verified-LXMF state, current active-Link availability, send readiness, and source classification (contact/announce/history/manual).
- Peer list rows now include a compact `seen` age in addition to hop count.
- Peer details provide direct CHAT, NAME, STAR and QR actions.
- Added `[v1.3:peer]` diagnostics when the details screen is opened.

## What did not change

- Reticulum packet encoding/framing.
- SX1262 radio service.
- LXMF message construction or send/retry behavior.
- Storage journal formats.
- v1.2 send-state overlay.
- Power, wake, audio and Codec2 behavior.

This release intentionally exposes already-known Reticulum state instead of changing the proven communications path.
