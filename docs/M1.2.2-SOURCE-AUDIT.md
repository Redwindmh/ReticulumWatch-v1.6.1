# M1.2.2 source/layout audit

- Baseline: immutable M1.2.1.
- Functional change is limited to `WatchUI::showCompose()` plus version/docs.
- `lv_keyboard_create()` is known to create a keyboard with default bottom alignment; M1.2.2 no longer applies `lv_obj_set_pos()` to that aligned widget.
- Keyboard remains associated with the existing textarea through `lv_keyboard_set_textarea()`.
- Existing APIs used elsewhere in the project (`lv_obj_align`, `lv_obj_set_size`, style padding setters, textarea calls) are retained.
- No changes to SX1262 profile, RNode framing, Reticulum endpoint setup, persistent identity, LMX1/LMX2 storage, LXMF parser/signature logic, or reply transport.
- Not build-verified in this environment.
