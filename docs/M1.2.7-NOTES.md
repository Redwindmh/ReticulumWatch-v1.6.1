# M1.2.7 — C++-typed LVGL keyboard control map

## Scope

M1.2.7 is a compile-fix patch for the watch-sized keyboard introduced in M1.2.6.
It does not change the keyboard layout, dimensions, modes, networking, LXMF wire
format, storage, radio profile, or Reticulum behavior.

## Failure in M1.2.6

The PlatformIO build reached `src/ui/WatchUI.cpp` and failed because custom keyboard
control-map expressions such as:

```cpp
LV_BUTTONMATRIX_CTRL_POPOVER | 1
```

have C++ type `int`, while the destination array is `lv_buttonmatrix_ctrl_t[]`.
LVGL's own keyboard implementation uses equivalent expressions in a `.c` file, where
that initialization is accepted. The same source pattern is not automatically valid
in C++.

## Fix

M1.2.7 routes every flag/width combination through constexpr helpers that explicitly
return `lv_buttonmatrix_ctrl_t`:

```cpp
constexpr lv_buttonmatrix_ctrl_t kbCtrl(uint32_t flags, uint32_t width) {
    return static_cast<lv_buttonmatrix_ctrl_t>(flags | width);
}
```

Plain width-only entries are likewise converted through `kbWidth()`.

The seven-column large-key layout from M1.2.6 is otherwise unchanged.

## Acceptance

1. `pio run -e twatch_s3_16mb` completes.
2. Flash without erasing the Reticulum partition.
3. Existing identity/history remain intact.
4. Establish a reply Link, open the composer, and verify lower/upper/special maps.
5. Send a message containing letters, digits, punctuation, spaces and backspace edits.
