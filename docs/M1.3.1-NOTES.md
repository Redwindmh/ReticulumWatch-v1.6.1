# M1.3.1 — Back-button usability patch

## Reason

M1.3.0 independent outbound messaging was hardware-tested successfully, but the 34x28 px top-left Back control was difficult to hit reliably on the 240x240 watch touchscreen.

## Functional change

Two navigation buttons are enlarged:

- message detail Back: 34x28 -> 44x32 px
- compose Back: 34x28 -> 44x32 px

The compose heading moves from x=38,width=128 to x=48,width=120 so it remains clear of the wider Back control and the existing 58x28 SEND button. The textarea and large-key keyboard geometry are unchanged.

## Frozen baseline

No changes are made to:

- `LxmfService` behavior (version string only);
- `StorageService` / LMX3;
- `RadioService`;
- `WatchLoRaInterface`;
- `ReticulumService`;
- RNS compatibility layer;
- SX1262 configuration/framing;
- keyboard maps or key geometry;
- HAL/power behavior.

## Verification status

M1.3.0 is build-verified and runtime/hardware-verified by user report. M1.3.1 is source-audited and archive-verified here, but must not be called PlatformIO build-verified until the user's actual `pio run` succeeds.
