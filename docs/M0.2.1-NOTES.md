# M0.2.1 — Dependency acquisition fix

M0.2.1 contains no intended runtime behavior changes from M0.2.

## Fix

M0.2 attempted to pin LilyGoLib with an abbreviated Git commit reference:

```ini
https://github.com/Xinyuan-LilyGO/LilyGoLib.git#38e6f8d
```

PlatformIO invokes a shallow Git fetch for VCS dependencies. An abbreviated SHA is not necessarily advertised as a remote ref, so Git rejected the fetch before compilation began.

M0.2.1 uses the published PlatformIO Registry package instead:

```ini
xinyuan-lilygo/LilyGoLib @ 0.2.0
```

This is a fetchable, version-pinned dependency and avoids relying on the moving `master` branch.

## Expected test

A successful dependency-resolution phase should show LilyGoLib 0.2.0 in the dependency graph and proceed into compilation. All M0.2 storage/radio acceptance tests remain unchanged.
