# M1.1 source audit

This archive was source-audited before packaging.

Checks completed:

- both 8 MiB and 16 MiB partition maps end exactly at flash capacity
- all project-local quoted includes resolve to files in the archive
- Reticulum/LXMF APIs used by the firmware were checked against RatSpeak
  microReticulum commit `290a1336ebe05782c80a1debf8a8da0316a88ae7`
- the endpoint setup was checked against rsCardputer v1.7.9
- `PROVE_ALL`, Link callbacks, packet destination hash access, transport callbacks,
  filesystem API, and `LXMFMessage::unpackFull()` signatures were verified
- LXMF announce metadata was corrected to advertise no compression support
- RadioLib's SX126x sync-word API was checked; the logical `0x12` setting remains
  intentional for this profile
- obvious source delimiter/truncation and missing-local-include checks passed

A full PlatformIO build was **not** run in the packaging environment because the
PlatformIO toolchain is not installed there and no cached package is available.
The first authoritative compile is therefore `pio run -e twatch_s3_16mb` on the
development machine.
