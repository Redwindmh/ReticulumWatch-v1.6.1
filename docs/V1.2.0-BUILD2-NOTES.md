# ReticulumWatch v1.2.0-build2

## Why this build exists

The original v1.2.0 artifact did not compile because `src/ui/WatchUI.cpp` contained a malformed `Serial.printf()` string literal in `WatchUI::sendEvent()`. The intended `\n` escape had been written as a literal newline in the C++ source, producing `missing terminating \" character` and `expected ')'` errors.

## Fix

- Restored the composer diagnostic to a valid one-line C++ string literal using `\\n`.
- No Reticulum, LXMF, radio, storage, power, audio, or packet-format code was changed.
- The v1.2 sending-message modal and deferred submission UX are unchanged.
- Added a release-preflight assertion for the exact escaped composer diagnostic so this failure mode is caught before packaging.
