# M1.2.1 source/API audit

This is a source-level regression record. It is **not** a substitute for an
actual PlatformIO build and on-device test.

## Immutable baseline

M1.2.1 was created from the user-proven M1.1.6 archive. The radio profile,
RNode-compatible one-byte framing, split-packet handling, SX1262 re-arm policy,
Reticulum endpoint construction, and full 40-character RatSpeak dependency pin
remain unchanged in behavior.

Pinned microReticulum commit:

```text
290a1336ebe05782c80a1debf8a8da0316a88ae7
```

## Captured-wire regression

The M1.1.6 serial capture that first delivered a real message to the watch was
used as a parser fixture.

The decrypted LXMF Link plaintext is 150 bytes and splits canonically as:

- destination hash: 16 bytes
- source destination hash: 16 bytes
- Ed25519 signature: 64 bytes
- MessagePack payload: 54 bytes

The 54-byte MessagePack payload decodes to the captured timestamp, an empty
title, `Message to RetWatch`, and the sender fields map.

Using the sender Ed25519 public key from the subsequent valid Reticulum
`LINKIDENTIFY` frame, the captured 64-byte LXMF signature validates against:

```text
hashed_part = destination_hash + source_hash + packed_payload
message_id  = SHA256(hashed_part)
signed_part = hashed_part + message_id
```

This test exposed and corrected M1.1.6's `Bytes::mid()` misuse. In the RatSpeak
fork the second argument is a length, so the correct calls are equivalent to
`mid(0,16)`, `mid(16,16)`, `mid(32,64)`, and `mid(96)`.

## Exact pinned-fork API checks

The source was checked against the exact pinned fork for these M1.2.1 calls:

- incoming callback `Packet::link()`
- `Link(Type::NONE)` and shared-copy semantics
- `Link::status()` / `Link::get_mdu()`
- `Link::set_packet_callback()` and `set_link_closed_callback()`
- `Packet(const Link&, const Bytes&, ...)`
- `Packet::send()` returning `PacketReceipt`
- `Identity::sign()` / `Identity::validate()`

LVGL 9.4 API use was checked for the text area, keyboard, vertical flex/scroll
container, and `lv_event_get_target_obj()` event handling.

## Persistence regression

- Existing `LMX1` files are read in place and are never rewritten merely by
  booting M1.2.1.
- New incoming/outgoing messages use `LMX2` with destination hash and direction.
- The existing message-count index and `/lxmf/inbox/%08lu.lxm` path are retained.

## Known limitation retained intentionally

The pinned fork's Link packet receipt proof validation is incomplete. M1.2.1
therefore treats a successful `Packet::send()` as a successful local encrypted
Link transmission only. It does not display a remote-delivered/read state.

## Build status

No PlatformIO executable/toolchain is available in the artifact-generation
environment used for this revision. Therefore M1.2.1 is **source/API audited but
not build-verified**. Build verification begins with the user's real PlatformIO
environment and must not be claimed until that build succeeds.
