# ReticulumWatch v1.6.1 Source Audit

Baseline: immutable v1.6.0 stable tree.

Runtime source changes are intentionally limited to:

- `src/config/BuildConfig.h`: version `1.6.0` -> `1.6.1`.
- `platformio.ini`: internal release marker `160` -> `161`.
- `src/ui/WatchUI.cpp/.h`: remove custom PTT-burst UI/callback/state; retain VOICE compose/playback; reflow thread action row; update voice status text.

Unchanged functional boundaries include:

- `src/reticulum/*`
- `src/radio/*`
- Reticulum/radio configuration and partition maps
- `src/audio/VoiceService.cpp/.h`
- `src/audio/AudioService.cpp/.h`
- LXMF/storage wire and journal formats
- power/wake implementation

The static preflight asserts exact hashes for the frozen Reticulum/radio boundary and explicitly checks that no PTT callbacks/button/state remain while the VOICE workflow is still present.
