# M1.3.3 — tactile control correction

## Why this patch exists

M1.3.2 hardware testing confirmed the enlarged controls, keyboard layout, visible composer cursor, LXMF receive, and M1.3 independent send path. The remaining reported defect was that button haptic feedback could not be felt reliably.

The attached M1.3.2 runtime log shows the DRV2605 initialized successfully, so this patch does not rework hardware discovery or PMU ownership. It corrects the user-facing haptic policy instead.

## Changes

- Normal LVGL buttons request haptic feedback on `LV_EVENT_PRESSED` rather than waiting for `LV_EVENT_CLICKED`.
- Functional button actions remain on `LV_EVENT_CLICKED`.
- Disabled buttons are explicitly ignored by the haptic callback.
- `WatchHardware::tapHaptic()` changes from DRV2605 effect 6 (Sharp Click, 30%) to effect 4 (Sharp Click, 100%).
- Keyboard haptics remain scoped to the keyboard's `LV_EVENT_VALUE_CHANGED`.
- No screen/root touch handler was added. Background taps and scrolling remain intentionally silent.
- Composer caret behavior from M1.3.2 is unchanged.

## Intentionally unchanged

- LMX3 storage and retention
- Reticulum identity persistence
- SX1262/RNode framing
- Radio parameters
- Reticulum runtime/interface
- M1.3 path-request/opportunistic outbound logic
- keyboard geometry/maps
- composer cursor implementation

## Acceptance test

1. Build and flash without erasing the Reticulum partition.
2. Tap `RST`, `ANN`, Back, a message row, `REPLY`/`SEND MORE`, `CANCEL`, and `SEND`; each enabled button should produce one short, clearly perceptible click as the finger goes down.
3. Tap/drag on empty screen space and scroll the inbox/message body; there should be no haptic.
4. If a button is disabled, pressing it should not produce haptic feedback.
5. Open the composer and type several letters/spaces/backspaces; each actual keyboard key should still produce one short click, and the visible caret should move correctly.
6. Send one message and receive one message to confirm M1.3 networking did not regress.
