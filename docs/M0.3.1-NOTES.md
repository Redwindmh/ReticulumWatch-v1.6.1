# M0.3.1 notes

Observed on M0.3 hardware test:

- `/reticulum` FAT mount and boot counter remained healthy.
- SX1262 initialization remained healthy.
- microReticulum reached its memory diagnostics, then threw `FileSystem has not been registered` on every boot.
- The failure happened before identity creation, so no valid M0.3 identity persistence test occurred.
- The diagnostic memory line overflowed the 240x240 page and made it vertically scrollable.

Fix:

- select microStore's ESP-IDF POSIX adapter (`USTORE_USE_POSIXFS=1`);
- initialize/register the adapter before `Reticulum::start()`;
- scope relative RNS storage under `/reticulum/rns` using the process working directory;
- use a fixed-size non-scrollable LVGL root and bounded diagnostic labels.
